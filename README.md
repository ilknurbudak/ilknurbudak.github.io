# ilknur budak

**Generative artist & creative coder** — Exploring the space where algorithms meet perception.

## Projects

### [Generative Grid — Sonik Kaleydoskop](https://github.com/illlknurbudak/creamav)
Audiovisual generative art — a living grid of blue tones that dissolves and reforms in bilateral symmetry, with real-time synthesized sound where each color triggers its own note.

### [Pareidolia — Gordugunu Sandigin Sey](https://github.com/illlknurbudak/080226_WC)
A 40-second interactive experience through five natural scenes (clouds, water, bark, soil, murmuration) built with Three.js. Challenges your perception: do you see faces where there are none?

### [Echo Masks — Algorithmic Echoes](https://github.com/illlknurbudak/ECHO-MASKS)
Generative mask-like forms created through flow fields and bilateral symmetry. Particles trace Perlin noise currents, accumulating brush strokes that the brain reads as faces. Built with p5.js.
